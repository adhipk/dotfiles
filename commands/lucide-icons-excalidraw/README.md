# Lucide Icons for Excalidraw

Search the Lucide icon set and copy icons as SVG files for Excalidraw.

## Usage

1. Run `Search Icons` in Raycast.
2. Search for and select an icon.
3. Press `Enter` to run `Copy Icon for Excalidraw`.
4. Paste into Excalidraw with `Cmd-V`.

The original `Copy SVG`, `Paste SVG`, `Copy Name`, and `Copy Component`
actions remain available in the action panel.
